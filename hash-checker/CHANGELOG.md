# Changelog
All notable changes to this project will be documented in this file.

The format follows Semantic Versioning (https://semver.org/).

---

## [1.0.0] - 2026-05-11
### Added
- Initial stable release of the Hash Checker tool
- Menu-driven CLI interface
- Support for MD5, SHA‑1, SHA‑224, SHA‑256, SHA‑384, SHA‑512
- Support for SHA‑3 (256)
- Support for SHAKE‑128 and SHAKE‑256 with variable-length output
- File hashing functionality
- Known-hash comparison feature
- Error handling for invalid input and missing files
- Clean output formatting
- No external dependencies
