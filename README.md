# Python Tools Suite

A collection of small, dependency‑free Python command‑line utilities.  
Each tool lives in its own folder, has its own README, and is designed to be simple, portable, and easy to understand.

This suite is intended for:
- Practicing Python
- Demonstrating CLI tool development
- Building a clean GitHub portfolio
- Providing useful utilities for everyday tasks

---

## Included Tools

### 🔹 Hash Checker
A file integrity verification tool that computes cryptographic hashes and optionally compares them to a known hash.  
Located in: `hash-checker/`

### 🔹 Password Generator
A simple tool for generating secure, random passwords.  
Located in: `password-generator/`

### 🔹 Web Scraper
A minimal example scraper for fetching and parsing webpage content.  
Located in: `web-scraper/`

### 🔹 File Comparator
A utility for comparing two files and checking if they match.  
Located in: `file-comparator/`
